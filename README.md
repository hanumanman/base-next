# Next.js Project

A modern web application built with Next.js 15, React 19, TypeScript, and Tailwind CSS.

## Features

- **Next.js 15** - The React framework for production
- **React 19** - The latest React version with improved performance
- **TypeScript** - For type safety and better developer experience
- **Tailwind CSS 4** - For utility-first styling
- **shadcn/ui** - Beautifully designed components built with Radix UI and Tailwind CSS
- **Tanstack React Query** - For data fetching and state management
- **Zustand** - Lightweight state management solution
- **React Hook Form** - For form handling with Zod validation
- **Dark Mode Support** - Via next-themes
- **ESLint & Prettier** - Code quality and formatting

## Getting Started

### Prerequisites

- Node.js (Latest LTS version recommended)
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone <repository-url>
cd 998
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## Available Scripts

- `npm run dev` - Starts the development server
- `npm run build` - Builds the application for production
- `npm run start` - Starts the production server
- `npm run lint` - Runs ESLint to check code quality
- `npm run format` - Formats code with Prettier

## Dependencies

### UI Components

- Radix UI components for accessible UI primitives
- Class Variance Authority for component styling variants
- Tailwind CSS for styling
- Lucide React for icons

### Data Management

- Tanstack React Query for data fetching
- Zustand for state management
- Axios for HTTP requests

### Forms

- React Hook Form for form handling
- Zod for validation

## Development Tools

- ESLint for code linting
- Prettier for code formatting
- TypeScript for type checking
